# 🚀 SmartKit

SmartKit is a modern collection of **100+ free online tools** built with **Next.js** and **TypeScript**.

The goal of SmartKit is to provide fast, accurate, and easy-to-use utilities for everyone—without requiring sign-up or downloads.

---

## 🌟 Current Features

### 💰 Finance Tools
- GST Calculator
- EMI Calculator
- Loan Calculator
- Income Tax Calculator
- Currency Converter
- Percentage Calculator

### 🧮 Utility Tools
- Age Calculator
- BMI Calculator
- QR Code Generator
- Character Counter
- Password Generator

## 🚀 Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
